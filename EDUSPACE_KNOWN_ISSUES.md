# EDUSPACE KNOWN ISSUES & LIMITATIONS

## 1. Текущий статус известных ограничений
На этапе релиза EduSpace 2.0 (MVP) **критических дефектов (P0) и блокирующих ошибок (P1) не зафиксировано**.

Все сценарии обучения студента, создания уроков преподавателем, начисления опыта и защиты данных протестированы и верифицированы. Ниже приводится перечень известных архитектурных допущений и ограничений первой версии MVP с планом их развития.

---

## 2. Перечень известных допущений (P2 / P3)

### 1. Отсутствие внешних ключей API в базовой поставке
- **Суть:** Если в среде развертывания не установлены переменные `GEMINI_API_KEY` или `OPENAI_API_KEY`, вызовы ИИ переключаются на детерминированный эвристический генератор.
- **Влияние:** Студент и преподаватель получают валидный, методически выверенный контент, однако отсутствует персонализированная генерация текста на произвольные редкие темы.
- **Решение:** Предоставить преподавателю возможность ввода собственного API-ключа в настройках профиля или настроить единый корпоративный ключ учебного заведения на сервере.

### 2. Поддержка видео-хостинга в блоках теории
- **Суть:** В текущей версии для видео используется встраивание внешних плееров (YouTube / RuTube / Vimeo через iframe) или локальных MP4-файлов.
- **Влияние:** Платформа пока не выполняет транскодирование видеофайлов в форматы HLS/DASH на стороне сервера.
- **Решение:** Во 2-й очереди развития подключить S3-хранилище (MinIO / Cloudflare R2) и сервис транскодирования.

### 3. Редактирование вариантов ответа внутри квизов конструктора
- **Суть:** Визуальный конструктор в текущей версии позволяет редактировать заголовок, текст, вопрос и параметры блоков прямо на форме, а сложные вложенные структуры (например, список из 5 вариантов ответа) инициализирует через шаблонные значения.
- **Влияние:** Преподаватель может захотеть произвольно увеличивать число вариантов ответа от 2 до 10.
- **Решение:** В следующем минорном обновлении добавить динамический список вариантов с кнопками «+ Добавить вариант ответа».

### 4. Ограничение многопоточного SQLite при высоких нагрузках
- **Суть:** Локальная СУБД SQLite при одновременной записи 100+ параллельных пользователей может возвращать `database is locked`.
- **Влияние:** Не актуально для учебного стенда до 50 человек, но критично для одновременного экзамена потока.
- **Решение:** Для промышленной эксплуатации колледжа переключать сервер на PostgreSQL (путем установки `DATABASE_URL`).
