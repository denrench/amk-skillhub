# АМК Практикум — Цифровая образовательная платформа

> **Полнофункциональный программный комплекс практического обучения и демонстрационных экзаменов для студентов Алматинского многопрофильного колледжа ([amk.edu.kz](https://amk.edu.kz), г. Алматы, ул. Жандосова, 63).**

---

## 🌟 Архитектура и возможности системы

Проект реализован по современной **клиент-серверной архитектуре (Fullstack)**:

* **Интерактивный банк заданий:** **50 производственных задач** (по 10 на каждую из 5 специальностей колледжа).
* **2 Режима прохождения:**
  1. 🎯 **«Свободный выбор»** — студент самостоятельно выбирает любые кейсы из списка для тренировки и наработки практического рейтинга.
  2. ⭐ **«По заданию учителя (Экзаменационные билеты)»** — сдача официальных билетов, назначенных преподавателем (Билеты №1, №4, №8) с контролем времени.
* **Frontend:** HTML5, CSS3 (высококонтрастная палитра Slate/Indigo, Flexbox, Grid, Custom Range, Canvas), Vanilla JavaScript (ES6+), Chart.js, собственный Web Audio синтезатор звуков.
* **Backend:** Python 3, Flask REST API, Werkzeug Security (хеширование паролей).
* **База данных:** SQLite3 (`database.db`) с реляционными таблицами пользователей (`users`) и ведомостей оценок (`grades`).
* **Аутентификация & Роли:** 
  - Раздельная регистрация и вход для **Студентов** и **Преподавателей**.
  - Регистрация преподавателя защищена секретным кодом колледжа: `AMK-TEACHER-2026`.
  - Электронный журнал преподавателя защищен паролем / ролью.
* **Деплой:** 
  - Онлайн: GitHub Pages (с умным fallback на сессионное хранилище).
  - Локально: Полный Fullstack-сервер на Python Flask с SQLite3.

## 💻 Быстрый запуск сервера с базой данных

### Вариант 1 (Windows в 1 клик):
Дважды кликните по файлу **`run_server.bat`** в папке проекта.

### Вариант 2 (Через терминал):
```bash
pip install -r requirements.txt
python server.py
```
Сервер запустится по адресу: **`http://127.0.0.1:5000`**
