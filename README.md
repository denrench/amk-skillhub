# AMK SkillHub — Платформа профессионального обучения АМК

> **Интерактивная образовательная экосистема и симулятор практических кейсов по специальностям Алматинского многопрофильного колледжа (amk.edu.kz).**

---

## 🌟 О проекте

**AMK SkillHub** — современная веб-платформа, разработанная для подготовки студентов колледжа АМК к производственной практике, демонстрационным экзаменам и чемпионатам **WorldSkills Kazakhstan**.

Вместо пассивного чтения лекций студенты получают доступ к **интерактивным симуляторам**, точно воссоздающим рабочую среду специалистов ключевых отделений колледжа.

---

## 🚀 Ключевые возможности

### 1. Интерактивные симуляторы по специальностям
* 💻 **06130100 — Программное обеспечение (IT):** Встроенная веб-песочница с редактором кода, компиляцией и автоматической проверкой юнит-тестами.
* 🚗 **07161300 — ТО и ремонт автомобильного транспорта:** Компьютерная диагностика через виртуальный сканер OBD-II, замер сопротивления и напряжения мультиметром, поиск обрывов цепи и сброс ошибок ЭБУ.
* ❄️ **07150900 — Монтаж и эксплуатация холодильно-компрессорных машин:** Интерактивная схема термодинамического цикла с хладагентом R134a, расчет холодильного коэффициента (COP), регулировка оборотов компрессора и вентиля ТРВ.
* 🎨 **02110300 — Графический дизайн:** Интерактивный аудит макета сайта, поиск дефектов композиции, контрастности и шрифтов (WCAG).

### 2. Паспорт компетенций (Radar Chart)
* Автоматическое построение круговой паутинки навыков студента по результатам сдачи практических кейсов (на базе Chart.js).
* Генерация цифрового сертификата с уникальным ID для отправки работодателям Алматы.

### 3. Режим Демоэкзамена
* Таймер обратного отсчета (45:00).
* Оценивание по модулям A, B, C по стандартам WorldSkills.

### 4. Дизайн и UX
* Трендовый темный дизайн (Dark SaaS / Glassmorphism) в стиле Vercel/Linear с акцентными неоновыми свечениями.
* Полная поддержка переключения тем (**Dark / Light**).
* Двуязычность (**Қазақша / Русский**) с мгновенным переключением без перезагрузки.

---

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3 (Custom Properties, Bento Grid, Flexbox), Vanilla JavaScript (ES6+).
* **Визуализация:** Chart.js (интерактивный радар компетенций).
* **Архитектура данных:** Модульная модель (`data.js`) с поддержкой `localStorage` для мгновенной интеграции с REST API / бэкендом (Node.js / Python).
