# АМК Практикум — Цифровая образовательная платформа

> **Полнофункциональный программный комплекс практического обучения и демонстрационных экзаменов для студентов Алматинского многопрофильного колледжа ([amk.edu.kz](https://amk.edu.kz)).**

---

## 🌟 Архитектура системы

Проект реализован по современной **клиент-серверной архитектуре (Fullstack)**:

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), Vanilla JavaScript (ES6+), Chart.js.
* **Backend:** Python 3, Flask REST API, Flask-CORS.
* **База данных:** SQLite3 (`database.db`) с реляционными таблицами студентов, учебных групп и экзаменационных ведомостей.
* **Деплой:** GitHub Pages (статический интерфейс) + локальный запуск полного сервера с базой данных.

---

## 🚀 Ключевые модули платформы

### 1. Интерактивные тренажеры компетенций (`simulator.html`)
1. 💻 **Инженерная песочница: Программное обеспечение (06130100)**  
   * Среда разработки алгоритмов с автоматическим тестированием краевых условий (V8 runtime runner).
2. 🚗 **Диагностический пост: Компьютерная диагностика ДВС и автоэлектрика (07161300)**  
   * Чтение кодов DTC по протоколу OBD-II (`P0301`), замер сопротивления мультиметром, физическая замена детали и очистка памяти ЭБУ.
3. ❄️ **Лабораторный стенд: Монтаж и эксплуатация холодильных машин (07150900)**  
   * Балансировка контура хладагента R134a, расчет холодильного коэффициента (COP), регулировка давлений HP/LP.
4. 🎨 **Мастерская экспертизы: Профессиональный UI/UX аудит интерфейсов (02110300)**  
   * Анализ соответствия стандартам веб-доступности WCAG 2.1 (AA), устранение дефектов сетки и типографики.
5. 🪑 **Технологический участок: Оптимизация карт раскроя плит ЛДСП (07221400)**  
   * ЧПУ-раскрой полноформатной плиты 2800×2070 мм на детали кухонного гарнитура с минимизацией технологического отхода (до 8.4%).

### 2. Кабинет преподавателя и электронный журнал (`teacher.html`)
* Электронная ведомость групп колледжа (**ПО-22, АВ-21, ХО-20**).
* Просмотр оценок студентов по каждому тренажеру в реальном времени.
* Итоговый средний балл (GPA) и статус сдачи Демоэкзамена WorldSkills.
* Функция официальной печати экзаменационной ведомости.

### 3. Карьерный навигатор рынка труда Алматы
* Интерактивный калькулятор дохода выпускников (от 250 000 до 950 000+ ₸/мес).
* Автоматический подбор квалификаций и компаний-партнеров в Алматы (*Kaspi.kz, Kolesa Group, Astana Motors, ТОО «АлматыХолод»* и др.).

## 🛠 REST API Спецификация

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Проверка статуса сервера и базы данных SQLite |
| `POST` | `/api/auth/login` | Авторизация студента или преподавателя |
| `GET` | `/api/grades?group=ПО-22` | Получение ведомости успеваемости по группе |
| `POST` | `/api/grades/save` | Сохранение результата прохождения тренажера в базу |
| `GET` | `/api/groups` | Список учебных групп колледжа |

## 💻 Быстрый запуск сервера с базой данных

### Вариант 1 (Windows в 1 клик):
Дважды кликните по файлу **`run_server.bat`** в папке проекта.

### Вариант 2 (Командная строка):
```bash
pip install -r requirements.txt   # Либо: pip install flask flask-cors
python server.py
```
Сервер запустится по адресу: **`http://127.0.0.1:5000`**
