# АМК SkillHub — Цифровая образовательная платформа (Google Stitch Edition)

> **Полнофункциональный программный комплекс практического обучения и демонстрационных экзаменов для студентов Алматинского многопрофильного колледжа ([amk.edu.kz](https://amk.edu.kz), г. Алматы, ул. Жандосова, 63).**
> **Дизайн-система:** [Google Stitch](https://stitch.withgoogle.com/projects/6021399497870026664) (Google Sans, Material Symbols, Obsidian Dark Canvas & Glass).

---

## 🌟 Возможности и Архитектура Системы

Проект реализован по современной **клиент-серверной архитектуре (Fullstack)** в дизайн-системе **Google Stitch**:

* **Дизайн-система Google Stitch:**
  - Фирменная типографика Google: `Google Sans`, `Google Sans Display`, `Google Sans Text`, `Google Sans Mono`.
  - Векторная библиотека иконок: `Material Symbols Outlined`.
  - Цветовая палитра: глубокий Obsidian Dark Canvas (`#0b0f19`), Google Blue (`#4285F4`), Google Red (`#EA4335`), Google Yellow (`#FBBC04`), Google Green (`#34A853`), неоновое свечение и 4-цветная акцентная лента Stitch.
  - Высококонтрастные карточки со стеклянным размытием (`backdrop-filter: blur(16px)`).
* **Интерактивный банк заданий:** **50 производственных задач** (по 10 на каждую из 5 специальностей колледжа).
* **2 Режима прохождения:**
  1. 🎯 **«Свободный выбор»** — студент самостоятельно выбирает любые кейсы из списка для тренировки и наработки практического рейтинга.
  2. ⭐ **«По заданию учителя (Экзаменационные билеты)»** — сдача официальных билетов, назначенных преподавателем (Билеты №1, №4, №8) с контролем времени.
* **Интерактивные рабочие станции симулятора:**
  - 💻 **IT**: Редактор кода и отладчик V8 Engine, запуск тестовых наборов и консоль вывода.
  - 🚗 **Авто**: Сканер ошибок OBD-II (DTC коды), 2-канальный осциллограф датчиков ДПКВ/ДПРВ, мультиметр.
  - ❄️ **Холод**: Анализатор термодинамического цикла с диаграммой p-h, переключатель R134a/R404A, балансировка перегрева ТРВ и счетчик COP.
  - 🎨 **Дизайн**: Аудитор контрастности по стандарту WCAG 2.1 AA, 12-колоночная адаптивная сетка, типографическая шкала.
  - 🪑 **Мебель**: 2D-оптимизатор раскроя плит ЛДСП 2800×2070 мм, компенсация ширины пропила пилы (4.4 мм) и минимизация отходов (<8%).
* **Backend:** Python 3, Flask REST API, Werkzeug Security (безопасное хеширование паролей).
* **База данных:** SQLite3 (`database.db`) с таблицами пользователей (`users`), сводных оценок (`grades`), каталога 50 заданий (`tasks`) и журнала сдачи работ (`task_submissions`).
* **Аутентификация & Роли:** 
  - Раздельная регистрация и вход для **Студентов** и **Преподавателей**.
  - Регистрация преподавателя защищена мастер-ключом колледжа: `AMK-TEACHER-2026`.
  - Электронный журнал преподавателя с дашбордом KPI, фильтрами по группам, рецензированием и экспортом в CSV.
* **Реактивный калькулятор дохода:** Интерактивный ползунок от 250 000 до 950 000+ ₸ с пересчетом квалификаций и работодателей в Алматы.
* **Звуковой движок:** Web Audio API синтезатор для тактильной звуковой обратной связи при кликах, верных ответах и сдаче работ.

## 🚀 Быстрый запуск сервера

### Способ 1: Двойной клик на Windows
Запустите файл `run_server.bat` в корневой папке проекта.

### Способ 2: Через командную строку
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python server.py
```
После запуска откройте в браузере:
- 🌐 Главная страница: `http://127.0.0.1:5000/`
- 💻 Станция симуляторов (50 задач): `http://127.0.0.1:5000/simulator.html`
- 👨‍🏫 Электронный журнал преподавателя: `http://127.0.0.1:5000/teacher.html`
- 🔑 Вход и регистрация: `http://127.0.0.1:5000/auth.html`
