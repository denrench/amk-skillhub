# АМК Практикум — Цифровая образовательная платформа

> **Полнофункциональный программный комплекс практического обучения и демонстрационных экзаменов для студентов Алматинского многопрофильного колледжа ([amk.edu.kz](https://amk.edu.kz), г. Алматы, ул. Жандосова, 63).**

---

## 🌟 Архитектура системы

Проект реализован по современной **клиент-серверной архитектуре (Fullstack)**:

* **Frontend:** HTML5, CSS3 (CSS Variables, Responsive Flexbox & Grid), Vanilla JavaScript (ES6+), Chart.js.
* **Backend:** Python 3, Flask REST API, Flask-CORS, Werkzeug Security (хеширование паролей).
* **База данных:** SQLite3 (`database.db`) с реляционными таблицами пользователей (`users`) и ведомостей оценок (`grades`).
* **Аутентификация & Роли:** 
  - Раздельная регистрация и вход для **Студентов** и **Преподавателей**.
  - Регистрация преподавателя защищена секретным кодом колледжа: `AMK-TEACHER-2026`.
  - Журнал преподавателя защищен паролем / ролью.
* **Деплой:** 
  - Онлайн: GitHub Pages (с умным fallback на сессионное хранилище).
  - Локально: Полный Fullstack-сервер на Python Flask с SQLite3.

## 🚀 Ключевые модули платформы

### 1. Авторизация и профили (`auth.html`)
* **Вход в систему:** проверка логина и пароля с валидацией через Werkzeug security hash.
* **Регистрация студента:** выбор группы колледжа (`ПО-22`, `АВ-21`, `ХО-20`, `ДИ-23`, `МЕ-21`), генерация студенческого билета `KZ-AMK-2026-XXXXX`.
* **Регистрация преподавателя:** выбор кафедры, верификация через мастер-код колледжа.
* **Динамический профиль:** в шапке сайта сразу отображается ФИО, группа и статус авторизации.

### 2. Защищенный кабинет преподавателя и журнал (`teacher.html`)
* Экран блокировки: неавторизованные пользователи не имеют доступа к оценкам.
* Фильтрация ведомости по группам колледжа: **Все группы, ПО-22, АВ-21, ХО-20**.
* Расчет среднего балла (GPA), количества сданных треков и аттестации WorldSkills.
* Кнопка официальной печати экзаменационной ведомости в формате А4.
* Мгновенное обновление данных из базы SQLite3.

### 3. Интерактивные тренажеры компетенций (`simulator.html`)
1. 💻 **06130100 — Программное обеспечение (IT):** Инженерный редактор кода с юнит-тестами начисления стипендии.
2. 🚗 **07161300 — Автодиагностика и ремонт:** Чтение кодов DTC через OBD-II, замер сопротивления катушки зажигания мультиметром (норма 1.1 Ом), замена детали, сброс Check Engine.
3. ❄️ **07150900 — Холодильные машины:** Балансировка контура хладагента R134a, компрессор, ТРВ-вентиль, расчет холодильного коэффициента COP.
4. 🎨 **02110300 — Графический дизайн:** Интерактивный аудит интерфейса макета колледжа по стандарту доступности WCAG 2.1.
5. 🪑 **07221400 — Производство мебели (ЧПУ):** Алгоритмический 2D раскрой полноформатной плиты ЛДСП 2800×2070 мм с расчетом технологического отхода (до 8.4%).
* Все баллы автоматически сохраняются в базу данных под аккаунтом вошедшего студента!

### 4. Карьерный навигатор рынка труда Алматы (`index.html`)
* Интерактивный калькулятор дохода выпускников (от 250 000 до 950 000+ ₸/мес).
* Каталог официальных специальностей колледжа с фильтрами и двуязычным интерфейсом (РУС / ҚАЗ).

## 🛠 REST API Спецификация (`server.py`)

| Метод | Эндпоинт | Параметры | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | — | Проверка статуса сервера и базы SQLite3 |
| `POST` | `/api/auth/register` | `email, password, full_name, role, group_name, teacher_key` | Регистрация студента или преподавателя |
| `POST` | `/api/auth/login` | `email, password` | Аутентификация пользователя |
| `GET` | `/api/user/profile/<id>` | — | Получение данных профиля и всех оценок студента |
| `GET` | `/api/teacher/journal` | `?group=ПО-22` | Защищенная ведомость успеваемости групп |
| `POST` | `/api/grades/save` | `user_id, specialty_slug, score` | Запись баллов за практический экзамен в базу |

## 💻 Быстрый запуск сервера с базой данных

### Вариант 1 (Windows в 1 клик):
Дважды кликните по файлу **`run_server.bat`** в папке проекта.

### Вариант 2 (Через терминал):
```bash
pip install -r requirements.txt
python server.py
```
Сервер запустится по адресу: **`http://127.0.0.1:5000`**
