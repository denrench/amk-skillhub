# EDUSPACE AI DOCUMENTATION

## 1. Архитектура и принципы интеграции ИИ
Искусственный интеллект в EduSpace спроектирован как надежный педагогический инструмент поддержки учебного процесса, а не декоративный чат-бот.

Ключевые принципы реализации:
1. **Безопасная серверная интеграция:** Все вызовы внешних моделей происходят строго через backend-сервер (`server.py` и `eduspace_ai.py`). Никакие API-ключи никогда не передаются на клиентскую сторону.
2. **Мульти-провайдерность:** Поддержка Google Gemini (1.5 Flash), OpenAI (GPT-4o-mini) и собственного детерминированного эвристического движка.
3. **Отказоустойчивость (Offline Fallback):** При отсутствии настроенных переменных окружения `GEMINI_API_KEY` или `OPENAI_API_KEY`, платформа не ломается и не выдает фиктивных галлюцинаций, а плавно переключается на встроенный педагогический генератор.
4. **Античит-защита (Anti-Cheat Guard):** ИИ для студента строго запрограммирован отказывать в выдаче прямых готовых ответов на проверочные вопросы и тесты.

## 2. Компоненты системы ИИ

### 2.1. AI-Ассистент преподавателя (`/api/ai/generate_lesson`)
- **Роль:** Методист-архитектор курсов.
- **Входные параметры:**
  - `topic` (строка): тема урока (например: «Flexbox и построение сеток»);
  - `discipline` (строка): дисциплина (например: «Веб-разработка»);
  - `difficulty` (строка): `beginner`, `intermediate`, `advanced`;
  - `duration` (число): продолжительность в минутах;
  - `objectives` (строка): желаемая цель обучения;
  - `lesson_type` (строка): формат урока (`theory`, `practical`, `visual`, `simulation`, `case`).
- **Выходной результат:** Валидный массив из 8 блоков урока (JSON), полностью готовый к загрузке в визуальный конструктор преподавателя.
- **Правило черновика:** Сгенерированный материал всегда сначала загружается как черновик. Только преподаватель имеет право верифицировать и опубликовать урок для студентов.

### 2.2. Сократовский AI-тьютор студента (`/api/ai/tutor`)
- **Роль:** Чуткий персональный наставник.
- **Интерфейс:** Боковая выдвижная панель (Drawer) внутри плеера уроков (`lesson_player.html`).
- **Педагогическая логика:**
  - Анализирует текущий открытый блок урока (`block_id`) и формулирует ответ в контексте изучаемой темы;
  - Приводит жизненные аналогии и примеры;
  - Задает наводящие вопросы («Как вы думаете, что произойдет с элементом, если изменить направление главной оси?»).
- **Механизм защиты от списывания (Anti-Cheat Guard):**
  - При обнаружении триггерных фраз («дай ответ», «какой ответ на тест», «буква а или б», «скажи правильный вариант» и т.п.) система активирует блокировку `anti_cheat_triggered: true`.
  - Тьютор вежливо отказывает в раскрытии правильного варианта и дает концептуальную подсказку по теоретическому правилу, направляя студента на самостоятельный вывод.

### 2.3. AI-помощник проверки заданий преподавателя (`/api/ai/review_submission`)
- **Роль:** Ассистент предварительной дефектовки студенческих работ.
- **Логика:** Сопоставляет код или текстовый ответ студента с техническим заданием, проверяет наличие критериев, рассчитывает рекомендуемый балл и готовит проект развернутого комментария.
- **Контроль преподавателя:** Окончательное решение и выставление официальной оценки в журнал всегда остается за человеком.

## 3. Таблица эндпоинтов и конфигурация

| Эндпоинт | Метод | Права доступа | Назначение | Фоллбэк без ключей |
|---|---|---|---|---|
| `/api/ai/generate_lesson` | POST | Преподаватель / Админ | Генерация 8-блочного урока | `heuristic_offline` (структурированный шаблон) |
| `/api/ai/tutor` | POST | Любой авторизованный пользователь | Сократовский чат-помощник | Контекстные подсказки по текущему блоку |
| `/api/ai/review_submission` | POST | Преподаватель / Админ | Предварительная проверка работ | Эвристический скоринг по чек-листу |
| `/api/ai/chat` | POST | Авторизованный пользователь | Общий AI-ментор платформы | База знаний колледжа АМК |

### Переменные окружения:
- `GEMINI_API_KEY`: API ключ Google AI Studio для модели `gemini-1.5-flash`.
- `OPENAI_API_KEY`: API ключ OpenAI для модели `gpt-4o-mini`.
- Если обе переменные отсутствуют, сервер регистрирует статус `[INFO] External AI keys not set. Operating in deterministic pedagogical offline mode.` и продолжает функционировать со 100% стабильностью.
