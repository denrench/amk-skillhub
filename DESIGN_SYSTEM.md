# DESIGN SYSTEM — AMK SKILLHUB × NYVOR

## 1. Visual Identity & Co-Branding
- **Co-Brand**: `AMK SkillHub × NyVor` (`NV`)
- **Typography**:
  - Display: `Bebas Neue` / `Oswald` (Cyrillic/Kazakh support, locally hosted WOFF2)
  - UI & Body: `Inter` 400/700 (locally hosted WOFF2)
  - Code & Telemetry: `JetBrains Mono` / monospace
- **3 Synchronized Themes**:
  1. `neon` (Default Cyber-Engineering Dark): `--bg: #070B14`, `--surface: rgba(15, 23, 42, 0.84)`, `--ink: #F1F5F9`, `--accent: #38BDF8`
  2. `graphite` (Industrial Workshop Dark): `--bg: #181A20`, `--surface: rgba(34, 37, 46, 0.9)`, `--ink: #F3F4F6`, `--accent: #C6FF3D`
  3. `light` (High-Contrast Daylight): `--bg: #F3F6FC`, `--surface: #FFFFFF`, `--ink: #0F172A`, `--accent: #2563EB`
- **Accessibility & Touch Targets**:
  - Minimum interactive pill/button height: `>= 26px` for compact header controls, `>= 36px` for primary CTAs.
  - Contrast ratio: `>= 4.5:1` for body text and form labels across all 3 themes.
