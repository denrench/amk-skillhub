# Развёртывание AMK SkillHub

Публичный учебник работает на GitHub Pages. Вход, регистрация, восстановление пароля, личные кабинеты и проверка работ обслуживаются Flask на Render. Страница аккаунта GitHub Pages проверяет доступность сервера и переводит пользователя на его домен. Пароль и код передаются только серверу аккаунтов.

## Настройка сервиса

В Render подключите репозиторий `denrench/amk-skillhub` и ветку `main`. Команды сборки и запуска заданы в `render.yaml`. Секреты добавляются в **Environment** сервиса.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Подключение к постоянной PostgreSQL. На хостинге приложение не переключается на временную SQLite. |
| `SESSION_SECRET` | Случайный постоянный ключ подписи сессий. Blueprint умеет генерировать его. Замена ключа завершит существующие сессии. |
| `MAIL_API_KEY` | Ключ отправки через Resend. |
| `MAIL_FROM` | Адрес отправителя на домене, подтверждённом в Resend. |
| `TEACHER_ACCESS_CODES` | При необходимости регистрации преподавателей. Служебные коды через запятую. |

Render блокирует исходящий SMTP на бесплатных веб-сервисах. Почтовый HTTP API работает независимо от SMTP-портов. [Render](https://render.com/docs/free) · [Подтверждение домена Resend](https://resend.com/docs/dashboard/domains/introduction)

## Проверка выпуска

1. В Render подтвердите, что развёрнут нужный коммит. Проверьте `/healthz` и `/api/auth/readiness`.
2. Через форму на публичной странице запросите код на контролируемый адрес. Проверьте доставку, регистрацию и вход в новом приватном окне.
3. Сбросьте пароль. Проверьте повторный вход и завершение старой сессии.
4. Перезапустите приложение и проверьте, что тестовый аккаунт остаётся доступен. Проверьте кабинет студента и преподавателя.

Локальная SQLite создаётся приложением автоматически. Не добавляйте базы с пользовательскими данными и секреты в Git.
